プライバシーポリシー（YouTube チャンネル運営ツール）

このページは、appuppu が自分の YouTube チャンネル（茂助スタジオ、世界を紐解く、アルゴリズム探検隊、毎日の煩悩）を運営するために使っている、自作のツールについての説明です。ツールの利用者は運営者本人のみです。

1. 取得する情報

  • 運営者本人の YouTube チャンネルの情報（チャンネル名、動画の一覧、公開状態、予約の時刻）
  • 運営者本人の動画の統計（再生数、高評価数、コメント数、視聴維持率などの YouTube アナリティクスの数値）
  • 運営者本人の動画に付いたコメントの本文（動画の改善の参考にするため）

2. 使い道

  • 運営者本人が作った動画の投稿、公開時刻の予約、概要欄やサムネイルの更新
  • 動画の反応を振り返り、次に作る動画の改善に役立てること

取得した情報を広告に使ったり、第三者に販売・提供したりすることはありません。

3. 保存と管理

認証情報と取得したデータは、運営者本人のコンピュータにのみ保存します。外部のサーバーには送りません（Google が提供する YouTube API、YouTube Analytics API、Google Drive API、Gmail API との通信を除く）。

4. Google API の利用について

このツールの Google API から受け取った情報の利用と他のアプリへの転送は、Google API サービスのユーザーデータに関するポリシー（限定的使用の要件を含む）に従います。YouTube のデータの扱いは、YouTube 利用規約と Google プライバシーポリシーにも従います。

5. アクセスの取り消し

このツールに与えたアクセス権は、Google アカウントのセキュリティ設定からいつでも取り消せます。

6. お問い合わせ

このページについてのお問い合わせは、サポートページからお願いします。
